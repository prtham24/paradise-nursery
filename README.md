
# Paradise Nursery 🌿

## Project Overview
Paradise Nursery is a React-based online houseplant shopping application. It allows users to explore indoor plants, add products to a shopping cart, change quantities, remove products, and view their total order amount.

## Features
- Attractive landing page with a Get Started button.
- About Us page describing the company.
- 18 houseplants across 3 categories.
- Product images, names, descriptions, and prices.
- Add to Cart functionality.
- Redux Toolkit for centralized cart management.
- Dynamic shopping cart item count.
- Increase and decrease product quantities.
- Remove products from the cart.
- Automatic total price calculation.
- Responsive design for different screen sizes.

## Technologies Used
- React.js
- JavaScript
- CSS3
- Redux Toolkit
- React Redux
- React Router
- Vite
- Lucide React

## How to Run the Project

1. Clone the repository.
2. Open the project directory.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in the terminal.
